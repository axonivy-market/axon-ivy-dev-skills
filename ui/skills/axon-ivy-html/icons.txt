Tabler Icons — curated names for Axon Ivy HTML Dialogs
Usage: class="ti ti-<name>"  (both classes required)

The font ships with the Axon Ivy platform — no install, no stylesheet import.

This is a CURATED subset, not the full catalogue. Tabler ships ~5800 icons.
Projects do NOT carry a tabler-icons.min.css to grep; for names beyond this
list, check https://tabler.io/icons (a name there maps to `ti-<kebab-name>`).

Many icons have variants that are NOT all listed below. Prefer extending a name
you can see here over inventing one. Common suffix patterns: -off, -plus, -minus,
-check, -x, -cancel, -search, -edit, -cog, -star, -heart, -share, -pin, -up,
-down, -bolt, -pause, -question, -exclamation, -dollar, -code, -discount.
